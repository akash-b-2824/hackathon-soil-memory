2. Abstract

This project presents a multi-source agricultural decision intelligence framework called Soil Memory + Future Simulation AI. The solution integrates five core modeling layers: crop recommendation, soil memory risk analysis, yield estimation, market price prediction, and fertilizer recommendation. Instead of using a single dataset and model, the framework combines multiple real-world Kaggle datasets and performs schema standardization, feature harmonization, and model-specific preprocessing.

The final system produces a ranked list of crop plans for a given farm context by jointly optimizing agronomic suitability, predicted yield, expected market price, and long-term soil sustainability. The prototype is implemented in both notebook form for experimentation and a FastAPI-based web application for practical usage and demo.

3. Introduction

Traditional crop selection decisions are often made using isolated indicators such as nutrient levels or historical habits. This approach can lead to reduced profitability, overuse of soil nutrients, and poor adaptation to changing climate and market signals. Modern precision agriculture requires integrated intelligence across soil chemistry, historical crop patterns, expected productivity, and economic outcomes.

The developed system addresses this need by combining data-driven learning and domain logic into one end-to-end pipeline. It supports both educational understanding and practical decision support through transparent model outputs and a clean interactive UI.

4. Objectives of the Study

  • Build a reliable crop recommendation engine from NPK and climate variables.
  • Design a soil memory mechanism to account for historical crop repetition effects.
  • Predict expected crop yield under location and season context.
  • Forecast market behavior to estimate likely crop selling price.
  • Recommend fertilizer strategies for post-harvest nutrient balancing.
  • Create a unified simulation score to rank crop plans for real decision support.
  • Deploy the complete solution in a browser-based mini-application.

5. Problem Statement

Farmers and planners need a decision framework that does not only answer “Which crop can grow?” but also answers:

  • Will the crop maintain long-term soil health?
  • What yield can be expected under current conditions?
  • Will market pricing make the crop economically viable?
  • What fertilizer intervention is needed after selecting that crop?

Existing single-model tools typically miss one or more of these dimensions. Hence, there is a need for a comprehensive multi-factor simulation system.

6.2 Data Preprocessing

  • Column names normalized to lowercase underscore format.
  • Categorical text cleaned with trim and lowercase standardization.
  • Numeric coercion applied to nutrient, weather, and price fields.
  • Missing-value handling through imputation in model pipelines.
  • Feature extraction from dates: year, month, day, and price spread.

6.3 Modeling Strategy

  • Crop Model: RandomForestClassifier with scaled numeric agronomic inputs.
  • Soil Memory Engine: district-level crop sequence weighting using lag features.
  • Yield Model: RandomForestRegressor on mixed numeric + categorical features.
  • Price Model: RandomForestRegressor with temporal + market + price spread signals.
  • Fertilizer Model: RandomForestClassifier for recommendation classes.

7. Data Analysis & Interpretation

7.1 Data Characteristics

  • Crop recommendation data is balanced across crop classes, ideal for supervised classification.
  • Yield data includes long-term regional trends useful for productivity modeling.
  • Market data shows strong relation between modal and min/max prices.
  • Fertilizer dataset has rich contextual attributes enabling good classification performance.

7.2 Feature Interpretation

  • NPK + pH + rainfall determine biological suitability in crop model.
  • Lagged crop repetition captures degradation risk patterns in soil memory.
  • Price spread captures market volatility and improves modal price fit.
  • Season and region contextualize both yield and price outcomes.

8.1 Combined Simulation Output

Final recommendations are generated by ranking candidate crops through a weighted score that includes crop suitability confidence, predicted yield, predicted market price, and soil memory risk penalty. This allows decision-makers to compare options rather than receiving a single rigid recommendation.

9. Conclusion

The project successfully delivers a complete multi-source AI framework for agricultural decision support. It goes beyond basic crop recommendation by incorporating sustainability (soil memory), productivity (yield), economics (market price), and intervention planning (fertilizer recommendation). The resulting system is technically strong, demo-ready, and aligned with real-world smart farming needs.

The dual implementation (notebook + API web app) ensures both research transparency and practical usability.
